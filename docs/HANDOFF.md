## Gotchas

- GitHub Pages basePath is `/vdc-academy` (only when `GITHUB_PAGES=true`).
- 3D scenes use `drei View` (one canvas). Any element above a scene needs `z-index` above 5 and must not be inside an `isolate` ancestor. `SceneSlot` must be inside a client component; pass `mood: 1` in the state for ink sections.
